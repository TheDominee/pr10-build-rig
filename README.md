# PR10 21×12 Build & Rig – viewer

Stage Effects Group (Pty) Ltd – 3D build and rigging viewer for the Eurotruss PR10 21×12 roof on a Layher stage.

Open it: https://thedominee.github.io/pr10-build-rig/

- 3D model of the full structure, 33-step build sequence, scaffold and ballast info
- Rigging planner (8 / 4 / UDL load cases from the Expo Engineering static report; 10 / 12 point are estimates) with PA arrays and DXF / MVR export
